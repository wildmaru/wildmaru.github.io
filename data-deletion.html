Data Deletion Instructions

Last updated: 2026-11-26

This application stores only the access tokens and account IDs of the owner's own accounts, on the owner's local computer. It keeps no data about anyone else.

Remove the app's access

  • Instagram: Settings → Apps and websites → Active → select this app → Remove.
  • Threads: Settings → Account → Website permissions → Active → select this app → Remove.
  • Facebook: Settings & privacy → Settings → Apps and websites → select this app → Remove.
  • YouTube / Google: Google account permissions → select this app → Remove access.
  • TikTok: Settings and privacy → Security and permissions → Apps and services permissions → select this app → Remove access.

Once access is removed the stored token stops working and is deleted from the owner's computer at the next use.

Request deletion

To ask for deletion of any data related to your account, open a request at this site's GitHub issues with the account name. The request is handled within 30 days and the result is confirmed in the same thread.
