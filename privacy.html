Privacy Policy

Last updated: 2026-09-28

This application is used only by its owner to upload videos to, and read the status of, the owner's own YouTube channels via the YouTube Data API.

It accesses only the owner's YouTube account data needed for those uploads. OAuth tokens are stored only on the owner's local computer. No data is collected from other users, sold, shared with third parties, or used for advertising.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The application uses YouTube API Services; see the Google Privacy Policy. Access can be revoked at any time at Google account permissions.
